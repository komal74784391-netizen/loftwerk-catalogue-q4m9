# Loftwerk Instruments - public catalogue

Static showcase site for the Loftwerk Instruments open-hardware collective.

- Instrument entries live in `content/instruments/` and carry YAML front matter.
- `_data/design-packages.json` lists candidate package repositories per entry.
- `_data/community-adoption.json` holds the quarterly community adoption sweep.

Build with any Jekyll-compatible generator; the site is deployed from the default
branch.
